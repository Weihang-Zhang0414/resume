# 快手（北京达佳互联信息技术有限公司）

**推荐算法实习生 - [电商]（AI 搜索策略算法）** | 2026年8月 - 2026年11月

**TL;DR:** 围绕快手电商 AI 搜索开展体验评估与效果调优，建立全链路 Badcase 归因方法锁定意图识别与 Planning 瓶颈；完成 21 万型号数据构造与两阶段模型调优（4.3亿预训练+300万精修），重构多层意图结构；扩展 Planning Agent 至 7 分类并完成 Qwen3-0.6B SFT，落地 GPT-4o 难样本自动化回流与 Summary 分步生成；推动电商意图搜索次数提升 +1.619%、商品意图搜索次数提升 +2.616%。

## 🎯 项目目标
深度参与快手 AI 搜索的体验评估与端到端算法调优。针对真实用户搜索场景中商品型号漏识别、聚合词误判、高约束 Query 改写偏移等痛点问题，通过数据工程、意图识别与 NER 模型调优、Planning Agent 架构升级及 Summary 链路重构，全面提升电商搜索结果精准度与转化效率。

## 💻 技术栈
Qwen3.8-27B, Qwen3-0.6B (SFT), GPT-4o, BERT, Intent Recognition (意图识别), NER (命名实体识别), Planning Agent, RAG 知识库, Active Learning (主动学习), A/B Testing, Python

## 🛠️ 我的核心贡献

### 一、竞品对比分析与全链路 Badcase 归因
* **多维评估口径建立:** 基于公司每日巡检的 500 条真实用户 Query Badcase，制定覆盖需求理解、商品供给、总结语、推荐语、Follow-up、响应耗时、后续行为等多维度的统一评测标准，系统对比快手与竞品的 AI 搜索表现。
* **首错追溯归因法:** 搭建覆盖“意图识别 → Query 改写 → 多源召回 → 过滤验证 → 总结生成 → 跳转转化”的全链路 Badcase 归因体系，对每条 Badcase 精准追溯首错模块，成功定位意图识别和 Planning Agent 为制约搜索体验的核心瓶颈。

### 二、意图识别与 NER 模型调优（核心工作）
* **痛点问题定位:** 线上分析发现两大核心问题：一是商品型号词漏识别，导致下游召回与改写缺乏型号约束；二是“xx大全”“xx推荐”等聚合词被误判为弱商品或种草意图，导致召回不稳定。
* **高质量数据体系构建:** 通过 NER 模型挖掘与 Qwen3.8-27B 二次校验构造 21 万条型号类样本；人工精标 10 万条数据（包含 0.6 万条困难样本，采用人工、BERT、GPT 三方交叉确认）；针对性清洗修正 37 万条聚合词标签。
* **两阶段模型训练策略:** 
  * **Step 1 泛化边界学习:** 基于 4.3 亿条大规模数据充分学习意图全局边界；
  * **Step 2 精品化修正:** 基于约 300 万高质量精标数据进行二次微调与精品化修正。
* **多层意图输出与 RAG 增强:** 将模型输出由二分类扩展为“一级意图 + 细粒度任务 + 完整 NER”的多层结构，沉淀标准化意图特征供下游改写、过滤与总结模块高效复用；同时引入多轮历史会话数据与 RAG 知识库，大幅提升品牌、主播等寻址类意图的识别准确率。

### 三、Planning Agent 优化与链路重构（核心工作）
* **分类体系演进与高约束直通:** 针对包含品牌+型号+规格等多维修饰的高约束 Query 易被过度改写导致召回偏移甚至空召回的问题，将 Planning Agent 分类从 6 类扩展为 7 类，新增“高约束”标签，使此类 Query 直接穿透进入多源召回，杜绝过度改写。
* **SFT 模型微调训练:** 按照全新标准重标 18.1 万条历史训练数据，补充 5 万条线上真实 Query，合并构建 205,383 条高质量训练集，微调 Qwen3-0.6B 完成 SFT 调优落地。
* **自动化 Badcase 回流闭环:** 抽取 430 条 Query 改写 Badcase，采用 GPT-4o 重新标注回流，构建 5K+ 难样本库；搭建每日自动化 Badcase 抽取与模型迭代流程。
* **Summary 链路重构:** 重构 6,406 条 Summary 训练数据，打破传统端到端生成，将总结语、推荐语和 Follow-up 拆解为分步生成架构，显著减少格式解析错误与追问跑题现象。
